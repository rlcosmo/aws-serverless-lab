# Capturas reais pendentes

grafana, kestra, glpi e argocd-placeholder são reservas visuais explícitas, não capturas. Não há interface ou métrica simulada. Não usar esses arquivos para comprovar integração.

Capturas definitivas e suas anotações dependem de acesso à UI, revisão de dados sensíveis e testes integrados aprovados. Registrar ferramenta/tela, horário, execução/GMUD, sanitização e hash. Setas devem destacar apenas elementos reais; legendas devem informar estado/limite. Não expor conta AWS, tokens, IPs internos, cookies, identidades pessoais ou dados do laboratório.
